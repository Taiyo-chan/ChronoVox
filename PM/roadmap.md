# 🗺️ Project Roadmap

**プロジェクト名**: voice_recorder_application
**概要**: 連続録音・プロジェクト振り分け・過去文脈を踏まえたAI議事録生成機能を持つiPhone（iPhone 12）向け音声録音アプリケーションの開発

## 📍 全体目標
1. **要件定義と技術スタック設計**
2. **録音・連続セッション・ファイル振り分け（コアUI）の実装**
3. **プロジェクト管理機能（概要・進捗・過去ログ管理）の実装**
4. **AIパイプライン（文字起こし・話者分離・文脈参照型議事録生成）の実装**
5. **実機（iPhone 12）テスト・ブラッシュアップ**

## 🗓️ マイルストーン・スケジュール

### 1. プロジェクト立ち上げ・要件定義
- [x] プロジェクト管理用フォルダ（PM, secretary, .agents）の作成
- [x] コアコンセプトの策定
- [x] 技術スタック・AI API・データ連携方式の決定（SwiftUI / ファイルアプリ連携 / Gemini API）

### 2. コア録音＆トリアージ機能の実装
- [x] 大型タイマー表示・基本ボイスメモ機能（録音・一時停止・波形・再生）の実装
- [x] 連続録音セッション機能の実装（連続録音・区切って次へ録音）
- [x] セッション終了後のファイル削除・プロジェクトフォルダ振り分け（新規作成含む）UIの実装

### 3. プロジェクト文脈＆AI議事録機能の実装
- [x] プロジェクトディレクトリ構造（`overview.md`・`current_status.md`・過去ログ）の管理機能
- [x] 音声書き起こし＆話者分離（人物別書き起こし）の連携（`gemini-3.5-transcribe` + `gemini-3.8-flash`）
- [x] プロジェクト文脈を踏まえた議事録生成パイプラインの実装（`current_status.md` 自動更新機能付き）

### 4. マルチリンガル・アイコン・Webアプリ（PWA）展開 ＆ 実機テスト
- [x] アプリ名を **ChronoVox** に改名・専用アプリアイコン（`AppIcon.png`）作成
- [x] 6言語対応（日本語・英語・フランス語・ドイツ語・イタリア語・韓国語）＆ AI文字起こし言語指定（`Automatic` + 6言語）
- [x] Webアプリ（PWA）版の実装と Netlify への公開完了（https://gilded-licorice-56aa77.netlify.app）
- [ ] iPhone 12 実機での運用テスト・追加機能のブラッシュアップ
